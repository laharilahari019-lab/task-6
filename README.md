# Context-Aware Dynamic Price Banding

## Objective
Develop dynamic percentile-based product price bands using Power BI and DAX.

## Key Features
- Dynamic 30th and 70th percentile thresholds
- Automatic recalculation based on slicers
- Context-aware pricing segmentation

## Insights
- Static price bands create misleading interpretations
- Dynamic percentile bands adapt to category-specific pricing behavior
- Filter context enables accurate comparative analysis
